# Store assets

Everything App Store Connect and the Google Play Console ask for, in one place. Texts to paste are in
[`listing.md`](listing.md). The icons, logo, splash and feature graphic are generated by
`scripts/brand/build-store-assets.sh` from the hero sprite `assets/charbaman.png`, so a change to the sprite
can be carried everywhere with one command.

## Logo (`store/logo/`)

| File | Use |
| --- | --- |
| `svg/logo-stacked.svg`, `logo-stacked.png` (1800 × 1500) | Main logo: badge above the wordmark |
| `svg/logo-horizontal.svg`, `logo-horizontal.png` (2277 × 600) | Banners, website header, feature graphic |
| `svg/logo-mark.svg`, `logo-mark-1024.png` | The round badge on its own (avatars, social profile pictures) |
| `svg/logo-wordmark.svg`, `logo-wordmark.png` | The name only |

The SVGs are the masters. Text is converted to outlines and the hero is drawn as vector squares, one per
sprite pixel, so they scale to any size without fonts or blur.

**Design notes.** The badge reuses the game's own pixel-art hero rather than a new drawing, so the icon, the
title screen and the runner all show the same character. He is cropped to head, glass and flexed arm (the parts
that still read at 60 px on a home screen) and rises from the bottom edge out of the orange sunburst used on the
title screen. A two-pixel cream outline separates his orange suit from the orange background. The wordmark is
Inter Black Italic in white with a dark-brown outline and drop shadow, matching the in-game "CHARBAMAN" title,
with "شربة مان" underneath. Colours come from `src/theme.ts`: orange `#FF7A00`, deep orange `#E85D04`,
light orange `#FFB347`, cream `#FFF4E6`, ink `#2B1300`.

In the logo and icons the blue band on the chest badge is recoloured green (the necklace's green), so the
round white-and-blue chest emblem does not read as a cola-brand globe at icon size. The in-game sprite still has
the blue; recolour `assets/charbaman.png` too if you want them to match.

## Apple App Store

| Asset | File | Notes |
| --- | --- | --- |
| App icon 1024 × 1024 | `store/ios/app-icon-1024.png` | RGB, no transparency, square corners (iOS rounds them). Same image as `assets/icon.png`, which EAS builds into the app. |
| iPhone 6.9" screenshots | `store/screenshots/ios-6.7/` (English), `ios-6.7-fr/`, `ios-6.7-ar/` | 1290 × 2796, accepted in the 6.9" slot; App Store Connect scales them down for smaller iPhones. |
| iPad screenshots | not needed | `ios.supportsTablet` is `false` in `app.json`, so the app is iPhone-only. |

## Google Play

| Asset | File | Notes |
| --- | --- | --- |
| Hi-res icon 512 × 512 | `store/android/play-icon-512.png` | 32-bit PNG, full square (Play applies its own mask) |
| Feature graphic 1024 × 500 | `store/android/feature-graphic.png` | Required |
| Phone screenshots | `store/screenshots/android-phone/` | 1080 × 1920 (9:16), 6 shots; Play needs 2 to 8 |
| Adaptive icon layers | `assets/android-icon-foreground.png`, `-background.png`, `-monochrome.png` | 1024 × 1024, wired up in `app.json`. The hero stays inside the 66 % safe circle. The monochrome layer is used for Android 13 themed icons. |

## In the app (`assets/`, referenced by `app.json`)

- `icon.png` (iOS and fallback icon), the three `android-icon-*` layers, `splash-icon.png` (the badge on the
  orange `#FF7A00` splash), `favicon.png` (web).

## Rebuilding

```bash
pip install pillow fonttools uharfbuzz       # Inter and DejaVu Sans fonts must be installed (paths in build-logo.py)
npm i -D playwright && npx playwright install chromium   # only if Playwright is not already available
bash scripts/brand/build-store-assets.sh
```
